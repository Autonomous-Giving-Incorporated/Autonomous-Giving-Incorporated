# Self-hosted suite fonts

Latin woff2 files for the AGI public site. Loaded locally so the Content-Security-Policy does not need `fonts.googleapis.com` / `fonts.gstatic.com`.

| `ibm-plex-mono-400.woff2` | IBM Plex Mono | SIL OFL 1.1 |
